# Claude Code mods

Mods for [Claude Code](https://code.claude.com), installed as plugins.

```
/plugin marketplace add nicolas-codemate/claude-code-mods
```

| Mod | What it does |
| --- | --- |
| [diff-review](plugins/diff-review) | Review pane for uncommitted changes, the pull request or one commit at a time: ask Claude about any line, read and settle GitHub review threads, all from the keyboard |
